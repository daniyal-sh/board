# D3 (`d3`)

Custom data visualisation: scales, axes, shapes, transitions, force layouts. For standard charts, `@observablehq/plot` is quicker (libs/plot.md).

```ts
import * as d3 from "d3";

const W = 640, H = 360, M = { top: 20, right: 20, bottom: 36, left: 44 };
const svg = d3.select("#chart").append("svg")
  .attr("viewBox", `0 0 ${W} ${H}`).attr("width", "100%").attr("data-part", "chart");

const x = d3.scaleLinear().domain([0, 10]).range([M.left, W - M.right]);
const y = d3.scaleLinear().domain([0, 100]).range([H - M.bottom, M.top]);
svg.append("g").attr("transform", `translate(0,${H - M.bottom})`).call(d3.axisBottom(x));
svg.append("g").attr("transform", `translate(${M.left},0)`).call(d3.axisLeft(y));

const line = d3.line<[number, number]>().x((d) => x(d[0])).y((d) => y(d[1]));
const path = svg.append("path").attr("fill", "none").attr("stroke", "var(--manim-blue)").attr("stroke-width", 3);

function update(data: [number, number][]) {
  path.datum(data).transition().duration(400).attr("d", line);
  svg.selectAll("circle").data(data).join("circle")
    .attr("r", 4).attr("fill", "var(--manim-yellow)")
    .transition().attr("cx", (d) => x(d[0])).attr("cy", (d) => y(d[1]));
}
```

- Use `viewBox` + `width="100%"` so charts scale on phones.
- `selection.join()` handles enter/update/exit in one call.
- Force simulations: `d3.forceSimulation(nodes).force("link", d3.forceLink(links)).force("charge", d3.forceManyBody()).on("tick", draw)`.
- Label axes with units (append `text` elements).
