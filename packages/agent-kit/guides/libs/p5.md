# p5.js (`p5`)

Creative coding on a canvas: quick simulations, particle systems, cellular automata, drawing tools, generative patterns. You write `setup()` once and `draw()` runs every frame. About 1.4 MB; use it when a hand-written Canvas 2D loop would be clumsy.

Always use **instance mode** (`new p5(sketch, element)`). Global mode puts hundreds of functions on `window` and collides with other code.

```ts
import p5 from "p5";

const host = document.querySelector<HTMLElement>("#sim")!;   // <div id="sim" data-part="simulation"></div>

new p5((p: p5) => {
  let balls: { x: number; y: number; vx: number; vy: number }[] = [];

  p.setup = () => {
    const c = p.createCanvas(host.clientWidth, host.clientWidth * 0.6);
    c.elt.setAttribute("aria-label", "Bouncing balls simulation");
    p.pixelDensity(Math.min(2, window.devicePixelRatio));
    balls = Array.from({ length: 20 }, () => ({ x: p.random(p.width), y: p.random(p.height), vx: p.random(-2, 2), vy: p.random(-2, 2) }));
  };

  p.draw = () => {
    p.background(14, 14, 18);
    p.noStroke();
    p.fill("#58C4DD");
    for (const b of balls) {
      b.x += b.vx; b.y += b.vy;
      if (b.x < 0 || b.x > p.width) b.vx *= -1;
      if (b.y < 0 || b.y > p.height) b.vy *= -1;
      p.circle(b.x, b.y, 12);
    }
  };

  p.windowResized = () => p.resizeCanvas(host.clientWidth, host.clientWidth * 0.6);
}, host);
```

- p5.js 2.x: there is no `preload()`. Make `setup` `async` and `await p.loadImage(...)` if you load an asset (import it from `lab/assets/` so it is inlined: `import url from "./assets/cell.png"`).
- Read controls inside `draw()` (e.g. a slider's value) instead of rebuilding the sketch when they change.
- Pause when it isn't needed: `p.noLoop()` / `p.loop()`, and stop on `prefers-reduced-motion` unless the student presses play.
- Input: `p.mousePressed`, `p.mouseDragged`, `p.touchStarted`. Set `touch-action: none` on the canvas when students drag on it.
- Colours: hex strings work everywhere (`p.fill("#FFE14D")`); keep the Manim palette for maths.
- `p.frameRate()`, `p.millis()` and `p.deltaTime` (ms since last frame) keep motion speed independent of the display.
- 3D: `p.createCanvas(w, h, p.WEBGL)` exists, but prefer Three.js for real 3D work.
- p5's "friendly error" messages are off in Board builds: mistakes surface as ordinary exceptions in `get_console`.
