An open-source companion to Apollo

A desktop app for teachers to make Manim videos, web animations and interactive Labs, released by the Apollo team. It borrows Apollo Study Space: Figtree, zinc surfaces, hairline borders, one solid indigo action per screen, blue for the assistant (like Teacher) and underlined tabs. It stays its own app, so there's no one-to-one parity.

Name Theme

Mark

All three keep Apollo's A, orbit and planet in its flat brand colours, so the app reads as family. Pick one to use it throughout.

Home

The same shell as Apollo: a grouped sidebar, a 52 px header with the section title, and one solid indigo action (Start). The project types work like Apollo's destination tiles, with a soft tint and a coloured icon. Recent projects form one bordered list, not a card grid.

Project

Focus mode, like Apollo's solving screens: the sidebar hides and one slim bar holds back, the title and the actions. The assistant docks on the right like Teacher, with a blue identity and a "Can see" line. Questions, approvals and activity sit inline.

Release

Marketed as an Apollo team project. The app itself never asks for an Apollo account.
